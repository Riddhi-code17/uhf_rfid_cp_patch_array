# uhf_rfid_cp_patch_array
UHF RFID patch antenna (865-868 MHz) project built in Ansys HFSS. Substrate: FR-4 Epoxy (\epsilon_r = 4.4, 1.6 mm thickness) Dimensions: 250 \times 250 mm patch Excitation: 50-ohm lumped port with dedicated integration line Sweep: 0.85–0.89 GHz for target band verification
